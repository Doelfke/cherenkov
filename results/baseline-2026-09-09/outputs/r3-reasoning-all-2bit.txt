To find the earliest time all 120 parts can be finished, we must determine the optimal allocation of work between Machine A and Machine B. Since both machines run simultaneously, the total time taken will be determined by the machine that finishes its assigned share of the work last.

Let $t$ be the total time in hours.
Let $N_A$ be the number of parts produced by Machine A.
Let $N_B$ be the number of parts produced by Machine B.

**Constraints:**
1.  $N_A + N_B = 120$
2.  $N_A$ and $N_B$ must be integers (partial parts do not count).
3.  The time taken by Machine A must be $\le t$.
4.  The time taken by Machine B must be $\le t$.

**Machine Parameters:**
*   **Machine A:**
    *   Setup time: 30 minutes = $0.5$ hours.
    *   Production rate: 8 parts/hour.
    *   Time to produce $N_A$ parts: $T_A = 0.5 + \frac{N_A}{8}$ hours.
*   **Machine B:**
    *   Setup time: 12 minutes = $\frac{12}{60} = 0.2$ hours.
    *   Production rate: 5 parts/hour.
    *   Time to produce $N_B$ parts: $T_B = 0.2 + \frac{N_B}{5}$ hours.

The total time $t$ must satisfy $t \ge T_A$ and $t \ge T_B$. To minimize $t$, we want to minimize $\max(T_A, T_B)$. This occurs when $T_A \approx T_B$, or when we find the integer pair $(N_A, N_B)$ that minimizes the maximum of their respective completion times.

### Step 1: Analyze the Continuous Case (Ignoring Integer Constraints)

Let's first find the optimal split ignoring the integer constraint to see where the balance lies.
Set $T_A = T_B$:
$$0.5 + \frac{N_A}{8} = 0.2 + \frac{N_B}{5}$$
Since $N_B = 120 - N_A$:
$$0.5 + \frac{N_A}{8} = 0.2 + \frac{120 - N_A}{5}$$
$$0.3 + \frac{N_A}{8} = \frac{120 - N_A}{5}$$
Multiply by 40 (LCM of 8 and 5) to clear denominators:
$$40(0.3) + 5N_A = 8(120 - N_A)$$
$$12 + 5N_A = 960 - 8N_A$$
$$13N_A = 948$$
$$N_A = \frac{948}{13} \approx 72.92$$

So, the optimal continuous split is approximately $N_A = 73$ and $N_B = 47$.
Since $N_A$ must be an integer, we should check the integer values around 72.92. Specifically, we need to check $N_A = 72$ and $N_A = 73$.

### Step 4: Check the Immediately Preceding Completion Time

The earliest time all 120 parts can be finished is **9.625 hours** (or **9 hours and 37.5 minutes**).
